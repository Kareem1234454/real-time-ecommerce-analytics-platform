# 1. Project Overview

Modern e-commerce platforms generate millions of user interactions every day. Every product view, search request, cart update, payment, and review creates valuable business data.

Traditional batch processing systems cannot provide immediate insights into these continuously generated events. Companies require near real-time analytics to monitor customer behavior, detect fraud, optimize inventory, and support business decisions.

This project demonstrates how modern Big Data technologies can be combined to build a scalable real-time analytics platform capable of processing thousands of events per second.

The platform simulates a real-world e-commerce environment by generating realistic customer activities, streaming them through Apache Kafka, processing them with Apache Flink, storing them in Hadoop HDFS, organizing them using Apache Hive, performing historical analytics using Apache Spark, and visualizing business metrics through interactive dashboards.

---

# 2. Business Problem

An e-commerce company needs answers to questions such as:

- How many customers are currently active?
- Which products are trending?
- What is the revenue generated during the last minute?
- Which payment transactions failed?
- Which users abandoned their shopping carts?
- Which products are running out of stock?
- Are there any suspicious payment activities?

Without a streaming analytics platform, these questions may only be answered hours later.

The objective of this project is to reduce this delay from hours to seconds.

# 4. Solution Overview

The platform consists of several distributed components.

Customer events are generated by a simulation service.

↓

Apache Kafka receives all incoming events.

↓

Apache Flink consumes the events, validates them, enriches them, and performs streaming analytics.

↓

Processed data is written into Hadoop HDFS using the Parquet format.

↓

Apache Hive provides SQL access to the stored datasets.

↓

Apache Spark performs historical analytics and scheduled reporting.

↓

Grafana displays live dashboards and operational metrics.

# 9. Data Sources

The project combines multiple data sources to simulate a real-world production environment.

## Master Data

Static reference datasets are used to enrich streaming events.

These include:

- Customers
- Products
- Categories
- Warehouses
- Inventory
- Sellers

The primary dataset used in this project is:

**Olist Brazilian E-Commerce Dataset**

Additional records may be generated using Python to increase the size of the datasets.

---

## Streaming Data

Unlike traditional datasets, streaming events are generated continuously.

A custom Python Event Generator simulates realistic customer behavior by producing events such as:

- Search Product
- View Product
- Add to Cart
- Remove from Cart
- Checkout
- Payment
- Review Submission

These events are published directly into Apache Kafka topics.

The Event Generator follows realistic customer journeys instead of creating random events. For example, a customer must view a product before adding it to the cart and complete checkout before making a payment.

---

## Historical Data

After processing, all events are stored inside Hadoop HDFS in Parquet format.

The stored datasets become the historical data layer used by Apache Spark for long-term analytics and reporting.
